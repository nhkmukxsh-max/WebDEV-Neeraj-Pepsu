Web Dev I Lab Assignment 3: Responsive Personal Portfolio Website

Lab Title & Description

Responsive Personal Portfolio Website (CSS Advanced) — A single-page portfolio built on previous lab work using modern CSS features including Flexbox, CSS Grid, mobile-first media queries, relative CSS units (rem, em, %, vw, vh), smooth hover transitions/transforms, and keyframe animations.

Sections Included

Header: Sticky navigation bar with brand logo and section links (Flexbox).

Hero: Introductory headline with animated role text, CTA buttons, and profile avatar (Flexbox).

About Me: Short background overview.

My Skills: Skill cards arranged in a responsive grid.

My Projects: Project showcase cards with tags and hover elevation.

Contact Me: Form with Name, Email, and Message inputs plus submit button.

Footer & Back to Top: Copyright notice, quick/social links, and floating scroll-to-top button.

Steps to View Responsive Behavior & Breakpoints Tested

Open index.html in a modern browser (Chrome, Edge, or Firefox) or serve it via VS Code Live Server.

Open Browser Developer Tools (F12 / Ctrl+Shift+I / Cmd+Option+I) and toggle Device Toolbar (Ctrl+Shift+M / Cmd+Shift+M).

Test across the following breakpoints and viewports:

Mobile (375px–767px / < 48rem): Hero stacks with text above the profile image; skills and projects stack in a single column (1fr).

Tablet (768px–1023px / 48rem): Skills expand to a 3-column grid, projects display in a 2-column grid, and footer items align horizontally.

Desktop (1024px+ / 64rem): Hero places text on the left and the profile avatar on the right; project cards arrange in a 3-column grid.
